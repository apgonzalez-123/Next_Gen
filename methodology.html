NextGen Methodology

How the room’s portfolio is built

Every number the guests and the projector see comes from the code on this page. This is the audit trail: the equity shelf and where its data came from, how each product is scored against the ten questions, how much each question counts, and a worked example against whatever the room has answered so far.

01From answers to buckets

Four sleeves. The specialist ones are carved out first, then equities and fixed income split what is left. Adding them on top instead made the result non-monotonic: a levered room ended up with less equity than an income-seeking one.

Every input is read from the aggregate rather than a modal pick, so the split moves smoothly as answers land instead of jumping when one option overtakes another.

03How an instrument is scored

For each question, the room’s share of every answer is multiplied by how well the instrument fits that answer. Those are averaged, then weighted by how much the question counts for that sleeve. One number per instrument, fully decomposable.

score = [ Σquestion wq · ( Σanswer sharea · fita ) ]  /  Σquestion wq

A fit is one of three shapes. A map, for a question answered by picking ({ig: 1.0, hy: 0.3}). An array, for an ordered question indexed by position. Or a target, for a question answered on a slider: the instrument sits at a point on the same range the guests answer on, and is scored by distance. The dollar share and duration both work that way.
